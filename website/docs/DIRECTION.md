# Estera — Night Atlas

The current implementation follows [the Night Atlas working contract](../EXPERIENCE.md), replacing the earlier simplified single-map layout at the user's request for a creative 3D scrolling website.

The existing black-canvas preference and Estera brand are retained. Native scrolling moves a real spherical atlas, then straightens the interactive product map. A warm paper comparison section, native FAQ and release availability dialog complete the product story. All animation is code-authored. No AI video, Blender, backend or download integration.

The three destinations are San Francisco, Tokyo and Paris. Globe geometry uses public-domain Natural Earth data; the local route preview remains explicitly schematic. See `public/assets/atlas-PROVENANCE.md` for geography provenance and `public/assets/CREDITS.md` for other credits.

The user's low-cost review boundary is unchanged: no automatic app/browser/dev-server launch or visual QA. Source-level compilation does not establish rendered quality.

# Research for the simpler redesign

The user requested a simpler full website, referencing “Ghost.” An optional clarification was sent; while pending, primary sources were studied for Ghost publishing, Ghostty and location-app GhostMe. The final design uses the common product-first hierarchy, with original composition and copy.

## Main references

### GhostMe — direct product-category reference
https://www.getghostme.com/

Directly read page content: short benefit headline, compact supporting statement, prominent product preview, plan choice, short feature explanations and FAQ. This is the closest category match. Adapted the economical sequence, not its pricing, claims, copy, app UI, screenshot or branding.

### Ghost
https://ghost.org/

Directly read page content: outcome headline, explanatory paragraph, primary CTA, then feature stories that each have one clear job. Adapted clear hierarchy and space for the product. The site's publisher-specific proof and content do not apply to Estera.

### Additional calibration
- https://ghostty.org/ — indexed primary homepage definition and Download/Documentation structure support a compact utility presentation. Root direct text extraction returned no body text; agent research used indexed text/source. No rendered appearance claim.
- https://cleanshot.com/ — product-specific workflow verbs and Mac-oriented calls to action, as observed through primary text/source by the research agent.
- https://downloadghostme.app/ — compact location/route proposition and download focus, read directly.

## Implemented decisions
White page, charcoal actions, bold sans-serif heading, one light map window, three short feature explanations, two edition cards, essential FAQ and compact footer. Blue belongs to the geographic selection/route. No globe, orbital annotations, decorative progress bar, repeated location scenes or long comparison table.

The Open/Pro switch changes the actual preview behavior. Open chooses a location from local demo places; Pro plays a route with speed/pause/reset. Native SVG/CSS/React is enough; the Three.js dependency was removed. The map is original and explicitly illustrative, with no live provider or copied screenshot.

## Evidence boundaries
Reference research used primary page text and search. No reference sites were opened in a browser or visually inspected, and no motion video was watched. Palette, spacing and composition are original design judgments, not claimed pixel matches. The app's local documentation and the user's edition split remain the sources for product claims. Release URLs, pricing and final hardware compatibility remain unset. Wi-Fi is not promoted as hardware-proven and Bluetooth is not advertised.

Verdict: serious fit found for structure. Reference only; simplify the existing implementation with native primitives and original product art.
